Casos mínimos:

1. Modelo disponible: `app para apicultores` debe producir augmentation estructurada.
2. Coincidencia conocida: `budget` no debe duplicar `presupuesto máximo`; debe añadir Apple como source provenance.
3. Concepto sectorial nuevo: debe conservar ID externo estable y `APPLE MODEL INFERENCE`.
4. Modelo no disponible: Local Expert debe producir un prompt completo.
5. Cancelación: no debe transformarse silenciosamente en una generación local nueva.

Compilar Foundation Models no demuestra disponibilidad runtime. Este checklist requiere dispositivo físico compatible.
