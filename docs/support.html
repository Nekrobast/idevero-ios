Qué es IDEVERO

IDEVERO convierte tu idea en un prompt que puedes copiar y usar en la herramienta que elijas. No ejecuta ChatGPT ni crea una aplicación por sí mismo.

Funcionamiento y compatibilidad

Funciona localmente con Local Expert en iPhone con iOS 17 o posterior. En sistemas iOS 26 o posteriores y dispositivos compatibles, puede complementar el resultado con Apple Foundation Models cuando el sistema lo tenga disponible. Si Apple Intelligence está desactivado, el modelo no está preparado o la inferencia falla, utiliza Local Expert. La primera preparación del modelo de Apple puede necesitar conexión; Local Expert no depende de ella.

Guardar y eliminar historial

Después de crear un prompt, pulsa Guardar. Comprueba la confirmación Guardado. Si se muestra un error, el resultado sigue disponible: reintenta o copia/compártelo. Abre Historial para consultar tus registros. Desliza un registro para eliminarlo. Las decisiones de un registro pueden actualizarse sin crear una cuenta.

Copiar y compartir

Copiar pone el prompt en el portapapeles. Compartir abre las opciones del sistema para enviar el texto al destino elegido. Revisa el contenido antes de enviarlo a otra aplicación.

Problemas frecuentes

  • Escribe primero una idea si Crear está deshabilitado.
  • Si el resultado usa conocimiento de IDEVERO, no es necesariamente un error: el fallback local es normal.
  • Si Guardar falla, conserva el prompt y reintenta; no desinstales la app como primer paso porque podrías perder historial.
  • Si no encuentras una recomendación, expande Ver más recomendaciones y desplázate.
  • Para soporte indica versión/build de Ajustes, versión de iOS y pasos para reproducir. No envíes prompts privados, identificadores del dispositivo, credenciales o certificados salvo necesidad explícita y consentimiento.

What IDEVERO is

IDEVERO turns your idea into a prompt you can copy into a tool of your choice. It does not run ChatGPT or build an application by itself.

How it works and compatibility

It works locally using Local Expert on iPhone with iOS 17 or later. On iOS 26 or later and compatible devices, it can augment results with Apple Foundation Models when the system makes the model available. If Apple Intelligence is disabled, the model is not ready or inference fails, it uses Local Expert. Apple's initial model preparation may require connectivity; Local Expert does not depend on it.

Saving and deleting history

After creating a prompt, tap Save and check for Saved confirmation. If an error appears, your result remains available: retry or copy/share it. Open History to view records. Swipe a record to delete it. Record decisions can be updated without an account.

Copy and Share

Copy puts the prompt on the clipboard. Share opens the system options for sending text to your chosen destination. Review the content before sending it to another app.

Basic troubleshooting

  • Enter an idea first if Create is disabled.
  • Seeing IDEVERO's built-in knowledge is not necessarily an error: local fallback is normal.
  • If Save fails, keep the prompt and retry; do not uninstall as a first step because history may be lost.
  • If you cannot find a recommendation, expand See more recommendations and scroll.
  • For support, provide app version/build from Settings, iOS version and reproduction steps. Do not send private prompts, device identifiers, credentials or certificates without explicit need and consent.
